## User Management System (Full Stack Project)
Developed a robust and scalable User Management System that efficiently performs CRUD (Create, Read, Update, Delete) operations. The frontend is built using ## React.js ## , providing a responsive and user-friendly interface, while Axios is used for seamless API communication. The backend is developed with Spring Boot, ensuring high performance and secure RESTful services. MySQL (RDBMS) is used for structured data storage and efficient data retrieval.

The system enables smooth user data handling with optimized database interactions, clean architecture, and proper error handling, making it suitable for real-world applications.
